一个必须说清的边界

Agent 写出来的稿子是毛坯房，不是精装交付。它不知道你的账号平时是什么调性、粉丝爱听什么梗，也分不清幽默和冒犯的线在哪。所以流水线的设计里，写作环节产出的永远只是初稿，最后一关必须是人。这套东西省掉的是重复劳动，不是判断力。
流程里两个工具：autocli 负责去各平台把热榜抓回来，zhihu-auto-publisher 负责把稿子投递到平台；中间用 Python 串起来，每一步都是函数，每个函数只做一件事。
