真实后端长什么样

真机版是 Flask + SQLAlchemy + SQLite，跑在 127.0.0.1:5001，核心就三件事：
① 定义模型 —— 一张 plan 表，字段 id / time / title / desc；
② 写路由 —— /add_plan 收 JSON、塞进会话、commit 落库，返回 {"msg":"新增数据成功"}；
③ 开跨域 —— 前端页面才能直接请求它。

@app.route('/add_plan', methods=['POST'])
def add_plan():
  data = request.get_json()
  plan = Plan(time=data['time'], title=data['title'], desc=data['desc'])
  db.session.add(plan)
  db.session.commit()
  return jsonify({'msg': '新增数据成功'})
这个页面里没有 Python，进程跑不起来；所以数据库换成本地存储、请求换成本地拦截，但请求体、响应、表结构、字段名都和真机一致，方便对着写前端。
