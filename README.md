# 个人作品集 · 部署说明

照下面 3 步做，就能得到一个能在浏览器直接打开的网址。

---

## 第 0 步 · 先解压（别直接把 zip 传上去）

GitHub 只是存文件，**不会帮你解压**。如果直接把 `portfolio-site.zip` 传上去，
网址打开会是一个下载链接，而不是网页。所以先在电脑上解压。

解压后会得到一个文件夹，里面是：

| 文件 / 文件夹 | 是什么 |
|---|---|
| `index.html` | 首页 |
| `works/` | 所有作品详情页、演示页、图片 |
| `admin.html` | 可视化后台（以后改内容用） |
| `.nojekyll` | 给 GitHub 看的标记文件，别删、别改名 |
| `README.md` | 就是本文，传不传都行 |

> **要传的是文件夹「里面的内容和文件夹」，不是那个文件夹本身。**
> 传错的表现：网址能打开，但显示 404 或一片空白。

---

## 第 1 步 · 建仓库 + 上传文件

1. 登录 github.com → 右上角 `+` → **New repository**

2. 仓库名二选一（这个决定了你最后的网址长什么样）：

   - 想要 `https://你的用户名.github.io` 这种最简网址
     → 仓库名必须精确写成：**你的用户名.github.io**
   - 想起个别的名字（比如 `my-portfolio`）
     → 网址会变成：`https://你的用户名.github.io/my-portfolio/`

3. 可见性选 **Public**（免费账号用 Public 最省事）；
   「Add a README file」**不要勾**

4. 点 **Create repository**

5. 进到仓库页面 → **Add file** → **Upload files**
   - 打开你解压出来的那个文件夹，`Ctrl+A` 全选里面的所有文件和文件夹
     （`index.html`、`works`、`admin.html`、`.nojekyll` …… 一起选中）
   - 一起拖进网页中间的上传区
   - 等进度条走完 → 点 **Commit changes**

---

## 第 2 步 · 打开 Pages 开关

仓库页面 → **Settings** → 左侧栏 **Pages**

| 选项 | 选什么 |
|---|---|
| Source | Deploy from a branch |
| Branch | `main` |
| 文件夹 | `/(root)` |

点 **Save**，等 1~2 分钟，然后打开你的网址：

- 仓库名叫 `你的用户名.github.io` → `https://你的用户名.github.io`
- 其它仓库名 → `https://你的用户名.github.io/仓库名/`

**自检**：首页能打开 → 点任意作品卡片能进详情页 → 详情页里的演示能直接玩/能看
→ 就算部署成功。

---

## 以后改内容（完全不用碰代码）

1. 打开你的网址后面加 `/admin.html`
   （例如 `https://xxx.github.io/admin.html`）
2. 在左边表单里改文字、加作品，右边会实时预览
3. 点右上角「⚡ 生成完整站点」，会下载一个新的 `portfolio-site.zip`
4. 解压后，把里面的 `index.html` 和 `works` 文件夹拖回仓库覆盖 → Commit

> 只改了文字的话，只覆盖 `index.html` 就够，会快一些。
> 如果改了演示页或图片，就要整包覆盖。

## 常见问题

**Q：为什么必须先解压？**
A：GitHub 不会自动解压。传 zip 上去，网址里只有一个下载链接。

**Q：`.nojekyll` 是干嘛的，能删吗？**
A：不能删、不能改名。GitHub 默认会跑一遍 Jekyll 处理网页文件，
加上这个空文件后它会原样输出，避免某些文件名被忽略、导致页面或图片 404。

**Q：打开后样式正常，但图片或演示一片空白？**
A：多半是只传了 `index.html`，没传 `works` 文件夹。回仓库确认 `works` 在里面。

**Q：能放多大的东西？**
A：本站点只有几 MB，GitHub 免费额度完全够。但别把 raw 素材、venv、exe
这类大文件传上去（单个文件超过 100MB 会被拒绝）。

**Q：网址谁能看？**
A：Public 仓库的 Pages 网址是公开的，任何人拿到链接都能访问。
别在页面里放隐私信息（手机号、住址、内部资料等）。

**Q：改完多久生效？**
A：Commit 之后一般几十秒到 1 分钟。浏览器记得强制刷新（`Ctrl+F5`）。
